# Automotive Marketplace 0.1.0-rc.1

Release candidate date: 2026-09-28. API compatibility remains `/api/v1`.

## Product scope

- Cars and Parts listing creation, lifecycle, moderation and public detail.
- Structured PostgreSQL/PostGIS Search/Geo with cursor pagination, facets,
  privacy-safe distance and server-assisted MapLibre clusters.
- S3-compatible direct media upload and asynchronous READY variants.
- Authentication, sessions, RBAC, account/security and administrative audit.
- Favorites, Saved Searches, notifications and transactional outbox processing.
- Listing-scoped messaging with Redis-backed Socket.IO multi-replica realtime.
- Durable asynchronous email intent/delivery.

## Release engineering and hardening

- Separate production Web and backend OCI images; the backend runs API,
  migrations and all three workers from distinct commands.
- Non-root/read-only reference containers, bounded shutdown and health/readiness.
- Version/SHA image publication workflow, SBOM, dependency/secret and Trivy gates.
- Production-like two-API TLS proxy topology with shared sessions, rate limiting,
  realtime and rolling restart validation.
- Prometheus-compatible low-cardinality metrics and safe database-outage 503.
- Deployment, monitoring, release, recovery, ownership and client handoff runbooks.
- Final runtime images omit the unused npm/npx toolchain; Trivy reports zero
  Critical/High findings for both release-candidate images.
- Final 27-scenario Playwright matrix, four-test security suite, two-replica
  rolling topology test and bounded TLS-proxy load smoke passed. Detailed local
  evidence is in the [release deployment report](../qa/release-deployment-report.md).

## Compatibility and migration

No new database migration was required by release packaging. The existing twelve
migrations remain authoritative, TypeORM synchronization stays disabled, and
application startup never migrates. The release preserves public `/api/v1`
contracts; no known intentional breaking API change is introduced by this stage.

## Status

Repository release artifacts are ready. Real staging/production rollout, provider
smoke, monitoring/on-call routing, client-approved catalogs, RPO/RTO, retention,
legal/IP and independent penetration testing remain external gates. See
[Known limitations](../handoff/known-limitations.md).
